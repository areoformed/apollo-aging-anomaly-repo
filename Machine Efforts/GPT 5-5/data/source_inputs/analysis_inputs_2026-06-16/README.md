This folder archives the actual upstream input files used by the prior Apollo mortality/survival scripts. It exists because output cohort labels such as `other_all` and `all_astronauts` are generated inside the script; they are not standalone dataset files.

`./Machine Efforts/Claude Compiled - Opus 4-6 and GPT 5-5 Processed Data`

This local archive preserves the relevant files under:

`data/source_inputs/analysis_inputs_2026-06-16/upstream_processed_data/`

## Generated Cohort Labels

These labels appear in output CSVs, but they are generated by `scripts/apollo_mortality_survival_analysis.py`:

| Cohort label | Construction | Standalone source file? |
|---|---|---|
| `apollo` | rows where `primary == "apollo"`; combines `07E-lunar-enriched.tsv` and `08E-non-lunar-apollo-enriched.tsv` | No |
| `other_all` | rows where `primary == "other"`; combines `03E`, `09`, `10`, and `11` files | No |
| `other_available` | `other_all` minus rows with `pre1970_accidental_death` | No |
| `all_astronauts` | `apollo + other_all` | No |
| `core_nasa_non_apollo` | rows where `source_key == "other_core_nasa"` | No, but it maps directly to `03E-non-apollo-enriched.tsv` |
| `military_only` | rows in `other_all` where `source_key` starts with `military_` | No |
